# GameCurfew · 游戏宵禁

> 给 Windows 上的《我的世界》定一个时间窗。窗口之外，游戏打不开，相关的网页、搜索、视频也一起拦掉。
>
> **单文件、零依赖、装完即生效。** 一个 PowerShell 脚本 + 两个双击就能用的启动器。

**中文** ｜ [English](README.en.md)

```
可玩时段   周五 12:00 → 周六 02:00（可改）
其余时间   拦住 MC 游戏本体 + 相关网页内容
家长自己   输密码临时解除，60 分钟后自动恢复
```

## 它解决什么问题

孩子用 Windows 电脑玩《我的世界》（网易国服版 / 国际版 / 通过 PCL、HMCL 等启动器），
还上网看 MC 视频、搜 MC 攻略。你想做的不是"禁止"，而是**划一个时间窗**——比如
「周五中午到周六凌晨可以玩，其他时间不行」。

难点不在于"禁止一个游戏"，而在于两件事同时成立：

1. **游戏有无数种启动方式**：官方启动器、PCL、HMCL、网易版、基岩版 UWP……
   按 exe 名字拦，永远漏。
2. **"上网搜相关内容"根本不在网络层可拦的范围内**（见下一节）。

## 为什么现成方案不够用

调研过一圈（速度、维护状态、能力覆盖），结论是**没有单一现成项目能覆盖**：

| 方案 | 为什么不够 |
|---|---|
| 网易官方防沉迷 / 家长平台 | 只覆盖网易自家游戏；且用成年人身份证实名即可绕过 |
| 微软家庭安全 | 网页过滤**只在 Edge 生效**；中国大陆可用性存疑（官方只给 Google Play / App Store 链接，中国区 App Store 页面 404） |
| AdGuard Home / Pi-hole / NextDNS | **DNS 层看不到搜索关键词**——见下 |
| OpenAppFilter | 需要 OpenWrt 路由器，是网络层应用识别不是进程拦截 |
| Portmaster | 能按进程断网，但**离线单人游戏照样能玩** |
| e2guardian | 唯一真正做内容关键词过滤的，但必须做 TLS 中间人 + 装本地根证书，Windows 上部署不现实 |

### DNS 层为什么挡不住"搜我的世界"

孩子在百度搜「我的世界」，请求是：

```
https://www.baidu.com/s?wd=我的世界
       ^^^^^^^^^^^^^^ 域名恒定
```

DNS 只看得到 `www.baidu.com`。要顺带封掉这个搜索，**只能整个封掉百度**——那正常学习用途也一起没了。
HTTPS 加密之后，路径和参数对任何网络中间人都不可见。

**这是本项目存在的根本原因。**

## 三个关键设计

### ① 用「窗口标题」挡网页内容，而不是中间人

窗口标题和浏览器地址栏在**本机是明文**的。孩子搜「我的世界」，窗口标题就是
`我的世界_百度搜索`；在 B 站看 MC 视频，标题带 `【我的世界】...`。

所以**不需要做 HTTPS 中间人、不需要装根证书**，就能拦住"搜关键词"和"看相关视频"。
这是本地手段里唯一可行的路子。

同时这也意味着拦截是**浏览器无关**的——Edge、Chrome、360 浏览器、便携版浏览器，
标题栏都藏不住。

### ② 拦 Java 版要靠命令行特征，不能靠 exe 名

PCL、HMCL、官方启动器**本身只是壳**。点"启动游戏"之后真正跑起来的是 `javaw.exe`——
把启动器杀了，游戏照样在跑。而 `javaw.exe` 是所有 Java 程序的通用名字，按名字拦会误伤一大片。

所以用**命令行特征**识别：

```
net.minecraft.client.main.Main     ← Minecraft Java 版的主类，所有启动器最终都调用它
--assetIndex                       ← MC Java 独有参数
```

不管启动器叫什么名字、装在哪个盘、`.minecraft` 挪到哪儿去了，这一个特征都能命中，
而且不可能误伤普通 Java 程序。

网易版则走 `MCLDownload` 安装路径 + `mc.163.com` 域名兜底。

### ③ 弱关键词必须累积，否则误报会淹没日志

`mc` 这个缩写如果单独命中就拦，会误伤：`cmd.exe`、`McDonald's`、`HMMC`、`MC 天佑`……

所以关键词分两级：

- **强特征词**（单独命中就拦）：`我的世界`、`Minecraft`、`迷你世界`、`Plain Craft Launcher`…
- **弱特征词**（要**同时命中 2 个**才拦）：`mc`、`红石`、`苦力怕`、`方块`…

拉丁词做词边界匹配（等价于 `\bmc\b`），中文词直接包含匹配。
回归用例里有 12 条专门盯这个，包括上面那几个陷阱。

## 功能一览

| 能力 | 说明 |
|---|---|
| 时间窗 | 「周五 12:00 → 周六 02:00」这种跨午夜区间，可随时改 |
| 进程拦截 | 进程名 + 安装路径 + 命令行**三重匹配**，覆盖官方 / PCL / HMCL / 网易版 / 基岩版 / 迷你世界 |
| 网页拦截 | 枚举所有可见窗口标题，关键词分级匹配后关窗口 |
| 域名兜底 | 拦截时段写 hosts，并关闭浏览器 DoH 防绕过，改完刷新 DNS 缓存 |
| 家长密码 | PBKDF2 加盐哈希（20 万次迭代），不存明文；**要求至少 8 位且非纯数字** |
| 命令鉴权 | 暂停、切只记录、改时段、卸载**都要验密码**；连续输错 5 次冷却 15 分钟 |
| 隐蔽 | 无窗口、无托盘、无安装记录、无启动项；计划任务设为 Hidden，跑在 SYSTEM 会话 |
| 抗移除 | 进程被杀 **1 分钟内自动回来**；hosts 被改 5 分钟内重写；脚本/配置被删自动恢复 |
| 日志 | JSONL 本地日志 + SYSTEM 定期归档 + 篡改检测 + 存活心跳 |
| 零依赖 | 不需要 Python / Node / .NET SDK，Windows 自带 PowerShell 就能跑 |

## 工作原理

### 两个计划任务

| 任务 | 身份 | 触发 | 干什么 |
|---|---|---|---|
| `SystemHealthMonitor` | 目标账户 | 登录时 + 每 1 分钟 | 每 0.9 秒枚举窗口标题，命中就关窗口；写日志 |
| `SystemHealthService` | SYSTEM | 开机 + 每 5 分钟 | hosts 切换、进程拦截、自愈、日志归档、心跳 |

**为什么必须是两个**：`SystemHealthService` 跑在 SYSTEM 会话（第 0 会话），
**看不到用户的窗口**；而关窗口必须在用户会话里做。反过来，改 hosts、结束任意进程
又需要 SYSTEM 权限。所以拆成两半，用 `IgnoreNew` + 每分钟重复触发实现"杀了就自己回来"。

### 三层拦截

| 层 | 手段 | 挡什么 |
|---|---|---|
| 进程层 | 三重匹配后结束进程 | MC 游戏本体、迷你世界 |
| 窗口层 | 窗口标题分级匹配后关窗口 | 百度搜关键词、B站刷视频 |
| 域名层 | hosts + 关 DoH | 直连 `mc.163.com` 等 |
| 自愈 | 进程/文件/hosts 定时校验修复 | 抗常见移除手段 |

### 隐蔽性是怎么做的

- 计划任务设 `-Hidden`，**在任务计划程序的默认视图里不显示**
- 用 VBS 静默启动器（`WScript.Shell.Run(..., 0, False)`），消除 PowerShell 的黑窗口闪现
- 不写安装记录、不放启动文件夹、不加托盘图标
- **安装后的痕迹刻意不叫项目名**：目录是 `C:\ProgramData\SystemHealth`，
  任务是 `SystemHealthMonitor` / `SystemHealthService`。
  一个不熟电脑的孩子翻到也不会联想到"家长控制软件"。

### 日志防删

日志文件**必须对目标账户可写**（否则监控进程根本写不进去）。这意味着目标账户理论上能删它。

所以：

- SYSTEM 任务每 5 分钟把新增日志归档到 `cache\`（该目录只有 SYSTEM/Administrators 有权限）
- 归档逻辑检测**行数变少**，判定为篡改并单独记一笔
- 日志轮转**统一由特权侧做**——如果让监控进程自己截断，行数骤降会被误判成"日志被删改"，
  刷出一堆假警报。**假警报比没警报更糟，它会让你不再信任日志。**

> 试过把日志权限收紧成"只追加不可删"来根治，**实测失败**：`(WD,AD)` 和 `(WD,AD,WEA,WA,RC)`
> 都会让 `Add-Content` 直接 Access denied（.NET 请求的是完整的 `GENERIC_WRITE` 掩码）。
> 对监控工具来说，静默失去全部日志比"日志可被删"严重得多，所以保留了 `(M)`，
> 用归档 + 篡改检测来补偿。

## 家长豁免：共用账户下怎么区分是你还是孩子

很多家庭**家长和孩子共用一个 Windows 账户**。这种情况下 Windows 眼里你俩是同一个人，
任何按账户判断的机制全部失效。

GameCurfew 的解法是**不区分人，改用一个只有你知道的密码**。

### 设密码

```powershell
.\gamecurfew.ps1 -SetPassword
```

- 只保存加盐哈希（PBKDF2-SHA256，20 万次迭代），**不保存明文，忘了找不回来**
- **至少 8 位，且不能是纯数字**（哈希文件对目标账户可读，短密码有被离线爆破的风险）

### 解锁：两种通路

**方式一 —— 交互式（推荐，密码不落盘、不进命令历史）**

```powershell
.\gamecurfew.ps1 -Unlock     # 输密码，暂停拦截 60 分钟
.\gamecurfew.ps1 -Lock       # 立刻恢复
```

**方式二 —— 环境变量（不需要管理员权限、不弹 UAC）**

```powershell
setx GAMECURFEW_PARENT "你的密码"
```

监控进程每轮读 `HKCU\Environment` 里的这个变量，用同一套盐和迭代次数算哈希比对：

- 比对通过 → 进入家长模式（默认 60 分钟）
- **无论通过与否，都立刻把这个环境变量删掉**，不让密码明文长期躺在注册表里

| | `-Unlock` | `setx` |
|---|---|---|
| 密码明文落盘 | 不落盘 | 短暂写注册表 + 可能进命令历史 |
| 需要 UAC | 需要 | **不需要** |
| 生效 | 立即 | 最多等一轮扫描（约 1 秒） |
| 自动过期 | 是 | 是 |

> 两种方式**都自动过期**。这是密码相对"静态开关"的关键优势——忘了锁回来也不会一直开着。

### 哪些操作要验密码

| 操作 | 要密码吗 |
|---|---|
| 暂停拦截 / 临时解锁 | ✅ 要 |
| 切换到「只记录」模式 | ✅ 要 |
| 改「能玩的时间」 | ✅ 要 |
| 彻底卸载 | ✅ 要 |
| 切回「真拦」、看日志、体检 | ❌ 不要（收紧限制不需要授权） |

连续输错 5 次后**冷却 15 分钟**，防止暴力猜测（`parentFailLimit` 可调）。

## 配置

配置文件：`C:\ProgramData\SystemHealth\settings.json`（改完 **15 秒内自动生效，不用重启**）

最常用的几个：

| 字段 | 说明 |
|---|---|
| `allowedWindow` | 可玩时段。`startDay`/`startTime` 起，`endDay`/`endTime` 止，**支持跨午夜**。星期用英文全称 |
| `mode` | `enforce` = 真拦（**默认**）；`dryrun` = 只记录不拦，排查误报时用 |
| `keywordsStrong` | 强特征词，单独命中就拦 |
| `keywordsWeak` + `weakThreshold` | 弱特征词，要同时命中 `weakThreshold`（默认 2）个才拦 |
| `action` | `CloseWindow` / `KillProcess` / `LogOnly` |
| `parentUnlockMinutes` | 解锁后多久自动恢复，默认 60 |
| `parentFailLimit` | 15 分钟内允许错几次，默认 5 |
| `domains` | hosts 兜底的域名清单 |
| `processNames` / `processPathMarkers` / `processCmdlineMarkers` | 进程拦截三重规则 |
| `exemptUsers` | 不监控的账户。**共用账户下无效**，用密码 |

例：改成「周五中午到周六早上 9 点」

```json
"allowedWindow": {
  "startDay": "Friday",  "startTime": "12:00",
  "endDay":   "Saturday", "endTime":  "09:00"
}
```

## 常用命令

```powershell
.\gamecurfew.ps1 -Wizard       # 一键：安装 + 设密码 + 体检
.\gamecurfew.ps1 -Menu         # 日常菜单（等于双击 日常.cmd）
.\gamecurfew.ps1 -SelfTest     # 体检：时间窗 + 关键词误报回归（不需要管理员）
.\gamecurfew.ps1 -Report       # 看日志汇总 + 存活心跳（不需要管理员）
.\gamecurfew.ps1 -TestTitle "我的世界_百度搜索"   # 测单条标题会不会被拦
.\gamecurfew.ps1 -SetPassword  # 设置家长密码
.\gamecurfew.ps1 -Unlock / -Lock                  # 解锁 / 立刻恢复
.\gamecurfew.ps1 -SetWindow "Friday 12:00,Saturday 09:00"   # 改可玩时段
.\gamecurfew.ps1 -ToggleMode   # 切换 拦截 / 只记录
.\gamecurfew.ps1 -Uninstall    # 彻底卸载
```

需要管理员的步骤会**自动弹一次 UAC**；`-SelfTest` / `-Report` / `-TestTitle` 不需要。

## 上手前请先做这两件事

### ⚠️ 1. 先去网易家长平台看一眼（零成本，优先级最高）

打开 **`jiazhang.gm.163.com`**（网易官方「未成年人护航平台」，免费）。

网易版官网明确写着：**未成年玩家只能在周五、周六、周日和法定节假日的 20:00–21:00 登录**。

也就是说，**如果孩子用的是自己实名的未成年账号，他周五下午根本进不去游戏——游戏自己就挡了**，
本项目有一大半时间用不上。反之如果他的账号用了成年人身份证实名，那防沉迷不生效，就得靠本项目。

**这一步比装软件优先。**

### ⚠️ 2. 装之前退出杀毒软件

本项目要做的事（建隐藏计划任务 + 用 wscript 启动隐藏窗口的 PowerShell + 改 hosts + 结束进程）
**正好是恶意软件的典型行为链**，火绒 / 360 / 电脑管家很可能拦截或隔离。

- 装之前：托盘图标右键 → 退出
- 装之后：把 `C:\ProgramData\SystemHealth` 加进白名单，再让杀软开机自启

这不是 bug，也不该用代码去绕（**绕过杀软本身就是恶意行为**）。

## 安全性说明

这是一个"家里自己用"的工具，威胁模型是**一个不太懂电脑的孩子**，不是专业对手。
在这个前提下，开发过程中修掉的问题记录如下，供审查：

| 问题 | 影响 | 处理 |
|---|---|---|
| 环境变量只在"未跳过"时被消费 | 暂停/豁免期间家长 `setx` 的密码会**永久明文留在注册表** | 改为**无条件读取并清除** |
| 暂停 / 切只记录 / 改时段 / 卸载**完全不校验密码** | 知道脚本存在即可绕过密码放行或卸载 | 全部接入 `Confirm-ParentAuth` |
| `parentFailLimit` 是死配置 | 密码可无限次暴力尝试 | 真正实现：15 分钟窗口计数 + 冷却 |
| 密码强度无要求 | 短密码的哈希可被离线爆破 | 至少 8 位、拒绝纯数字 |
| 卸载无条件删 `DnsOverHttpsMode` | 会误删**别人**在这台机器上设的策略 | 只在值确实是 `off` 时才删 |
| 卸载不清理遗留的环境变量 | 密码可能留在注册表 | 一并清除 |
| 日志轮转放在监控进程里 | 行数骤降被误判成"日志被删改"，刷假警报 | 轮转统一交给特权侧 |

### 已知的、未修的安全边界

- **日志文件可被目标账户删除**（必须可写才能记录）。缓解：归档 + 篡改检测 + 心跳。
- **`settings.json` 可被目标账户读取**，包括关键词表和密码哈希。缓解：哈希用 PBKDF2
  20 万次迭代 + 强制密码强度；关键词表靠"不显眼"而非加密。
- **目标账户是管理员时可停任务、删文件、改注册表。** 纯软件方案在管理员面前只是提高门槛。
- **忘了密码只能手工卸载**（`-Uninstall` 会拒绝），步骤在卸载失败时会打印出来。

## 常见问题

**会被孩子发现吗？**
软件本身藏得住（无窗口无托盘、任务隐藏、目录名中性）。但**"被拦"这件事藏不住**——
视频突然关掉、游戏打不开，他一定会察觉。建议**规则让他知道，实现藏起来**，
具体理由见「设计取舍」。

**孩子是管理员能绕过吗？**
能。任何纯软件方案在管理员面前都只是提高门槛。但如果不熟电脑，他不会去翻任务计划程序
或 `C:\ProgramData`。真正的分界线是「账号类型 + 物理/固件层控制」。

**为什么安装后的文件叫 `SystemHealth` 而不是项目名？**
故意的。中性名字不容易引起联想。

**记录一直是空的？**
① 现在可能正好在可玩时段，本来就不拦；② 被杀软拦了——跑 `-SelfTest`，
看「特权任务最后运行」是不是超过 12 分钟，是的话就是被禁用了。

**能管手机吗？**
不能。这是 Windows 专用方案。

**能挡住抖音/快手里的 MC 视频吗？**
不能。它们的 PC 客户端窗口标题是固定的应用名（如「抖音」），不含视频标题。
要么把 `douyin.exe` 加进 `processNames` 整应用禁掉，要么不管。
**B站网页版、百度搜索不受此影响。**

**忘了密码怎么办？**
改时段、卸载这类操作会拒绝执行，但会打印**手工卸载步骤**
（删两个计划任务 + 删目录 + 清 hosts 段落）。

## 已知限制

1. **目标账户是管理员 → 全部可绕过。** 安全模式、重装系统同理，无解。
2. **杀软可能拦截**（见上）。
3. **手机 / 平板完全管不到。**
4. **抖音/快手等原生客户端的窗口标题是固定应用名**，抓不到里面播的是什么。
5. **网页版 / 在线小游戏 MC** 标题可能是通用的，抓不到。
6. **共用账户下 `exemptUsers` 无效**，用家长密码。
7. **日志可被目标账户删除**（实测无法收紧 ACL），靠归档 + 篡改检测补偿。
8. **关键词表可被读到**：`settings.json` 对目标账户可读（监控进程要读它）。
   这里能做的是"不显眼"，不是"加密"。
9. **计划任务注册和 ACL 设置未经实机验证**（开发机无管理员权限，且作者不在生产机上测试）。

## 设计取舍

**为什么默认就是 `enforce`（真拦），而不是先观察？**
因为家长要的是"装完就管用"。代价是可能误伤自己——所以配了密码解锁（自动过期）
和一键切「只记录」模式作为退路。

**为什么不做 HTTPS 中间人做真正的内容过滤？**
需要装本地根证书、HTTPS 拦截会导致证书固定类应用出错、Windows 上部署不现实。
用窗口标题能达到 95% 的效果，代价是零。

**为什么默认不区分用户？**
共用账户下技术上区分不了；而独立账户场景下也**不需要区分**——
核验标准是"你不需要访问 MC 相关内容"，而不是"你是谁"。

**为什么不把界面做成图形程序？**
图形程序有窗口、托盘图标、安装记录，全都违反"隐蔽"这个核心需求。
PowerShell + 计划任务没有这些痕迹，而且零依赖。

**`.cmd` 里为什么一个中文都没有？**
cmd.exe 按**字节偏移**读取批处理文件。任何代码页切换（`chcp`）或非 ASCII 字节
都会让偏移错位，把行从中间劈开（实测报错形如 `'ent' 不是内部或外部命令`）。
所以启动器保持纯 ASCII 0 字节非 ASCII，中文 UI 全部交给 PowerShell 输出——
PowerShell 用 Unicode 控制台 API，任何代码页下都正常。

## 文件说明

| 文件 | 说明 |
|---|---|
| `gamecurfew.ps1` | 主程序。安装 / 监控 / 特权 / 卸载 / 自检全在这一个文件里 |
| `安装.cmd` | 一键安装启动器（双击用，纯 ASCII） |
| `日常.cmd` | 日常菜单启动器（双击用，纯 ASCII） |
| `傻瓜指南.md` | 逐步操作指南，含"每一步应该看到什么" |

安装后在目标机上展开：

```
C:\ProgramData\SystemHealth\
    ├─ settings.json   配置（可读，改完 15 秒生效）
    ├─ trace.log       拦截日志（JSONL）
    ├─ core.ps1        窗口监控
    ├─ admin.ps1       特权任务
    ├─ runc.vbs / runa.vbs   静默启动器
    └─ cache\          SYSTEM 专属：归档、心跳、脚本备份
```

## 卸载

双击 `日常.cmd` → 选 `6` → 输入 `Y` → 输入家长密码。
会删掉两个计划任务、hosts 屏蔽段、写入的 DoH 注册表项、遗留的环境变量、
以及整个 `C:\ProgramData\SystemHealth` 目录。

```powershell
.\gamecurfew.ps1 -Uninstall
```

> 忘了密码：卸载会被拒绝，但会打印手工卸载步骤。
